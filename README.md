# Santo Rosario sin Internet

Página web de la app **Santo Rosario sin Internet**: https://rezoelsantorosario.app

App gratuita para Android para rezar el Santo Rosario sin conexión, con audio y texto sincronizados, sin anuncios y sin registro. Una iniciativa sin ánimo de lucro de voluntarios de la Agrupación Santo Rosario.
